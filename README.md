# ABSA SME Management System

The **ABSA SME Management System** is a full-stack business management platform designed for Small and Medium Enterprises. The system provides secure identity management, organization isolation, financial tools, inventory management, and employee operations — all within a clean and modern interface.

---

## ✅ Features

### 🔐 Authentication & Security
- Secure login & registration using **ASP.NET Core Identity**
- Role-based access control (Admin, Manager, Employee)
- Every user belongs to an **Organization**
- Data isolation ensures companies cannot view another company’s data

### 💰 Finance Tools
- Record and manage business expenses
- Approve and reject pending expenses
- Generate invoice totals, track spending, and financial history
- Manager dashboards with real-time totals

### 📦 Inventory & Product Management
- Add new products/services
- Track item availability
- Attach organization ownership to prevent cross-company leaks

### 👥 Employee Features
- Employees can submit data or requests
- Managers approve/reject operations
- Audit trails for accountability

### 📊 Dashboard & Analytics
- At-a-glance overview of business health
- Pending vs approved expenses
- Activity summaries and quick actions
